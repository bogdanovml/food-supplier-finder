## Порядок работ и зачем так

Ядро → источники → пайплайн → API → UI: каждый слой тестируется curl-ом
до появления UI, чтобы фронт не-debug-ил бэк.

## Демо-сценарий (для README)

1. «мука пшеничная в/с» / Москва → видно 8 этапов → таблица ~15–30 поставщиков
   с ценами из госконтрактов и каталога.
2. Кликаем 3 карточки → сравниваем цены → заметка «звонить после 14:00».
3. RFQ: генерируем письмо, отправляем поставщикам с email.
4. Экспорт XLSX.
