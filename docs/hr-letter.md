# Письмо HR (черновик)

**Тема:** Тестовое задание «Food Supplier Finder» — готово

Добрый день!

Направляю выполненное тестовое задание — сервис **Food Supplier Finder**: поиск,
проверка и сравнение оптовых поставщиков продуктов питания.

**Демо:** https://maxim.org.ru/supplier-fnder/ (зеркало: https://maxim.org.ru/supplier-finder/)
**Репозиторий:** <ссылка на GitHub/GitLab>

## Что умеет прототип

Закупщик вводит товар («мука пшеничная в/с», «икра лососевая») и регион —
и за 3–7 минут получает таблицу поставщиков, с каждым из которых можно
заключить договор: проверенное юрлицо, телефоны/email, цены по предмету
запроса, минимальный заказ, условия доставки, выручка и прибыль из
официальной отчётности ФНС, опыт госконтрактов 44-ФЗ, рейтинг на Яндекс Картах.

## Ключевые решения

1. **Юрлицо прежде всего.** Карточка без ИНН/ОГРН для закупщика бесполезна —
   как «контакт» из обрубка телефона. В выдаче только верифицированные
   юрлица; всё отсеянное видно на отдельной вкладке с причиной отсева
   (аноним / ликвидировано / чужой город).
2. **Официальные первоисточники.** Статус, выручка, чистая прибыль и активы —
   из ресурса БФО ФНС (bo.nalog.gov.ru, открытый API без ключей). Реквизиты —
   ЕГРЮЛ через DaData. Ни одна цифра в досье не появляется без провенанса:
   в UI видно, откуда получен каждый факт.
3. **Deficit-waterfall.** Все дефицитные карточки дорабатываются: от дешёвых
   источников к тяжёлым, с кэшированием и вежливым троттлингом. Повторные
   поиски не тратят лимиты внешних API.
4. **LLM по делу.** Двухуровневая маршрутизация: дешёвая модель — планирование
   запросов, вычитка якорей ссылок, контакты из футеров; глубокая — цены
   строго по предмету запроса и черновики RFQ. Классификатор ссылок главной
   страницы (словарь → LLM на дефицит) находит прайсы и реквизиты даже
   там, где страницы называются «Витрина» или «Юр. информация».
5. **Честная деградация.** Ни капч, ни обходов WAF: если источник закрыт —
   это видно, но не ломает поиск. Антибот-защиты сайтов обходятся
   легальным headless-рендером там, где httpx не проходит.

## Стек

Python 3.12 / FastAPI (SSE-транспорт), SQLite, Playwright, httpx,
Tabulator.js + Bootstrap. Запуск одной командой `./run.sh`, все ключи в
`.env` (в репозитории только `.env.example`).
